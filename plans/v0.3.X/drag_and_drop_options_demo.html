Option A Evaluation

  • Feel: Modern, organic, animated.
  • CPU during Drag: ~1.2% (Continuous frame shifts).
  • Edge Cases: Requires spatial hysteresis dead-zones to prevent rapid jitter if mouse lingers between two slots.

Option B Evaluation (Recommended)

  • Feel: Precise, crisp, retro/classic feel.
  • CPU during Drag: ~0.1% (Only moves 1 lightweight marker).
  • Edge Cases: Zero jitter; target slot is always 100% unambiguous before release.

Option C Evaluation

  • Feel: Utilitarian, minimal.
  • CPU during Drag: < 0.05% (Pure floating layer).
  • Edge Cases: Higher cognitive load guessing which slot will receive the drop.
