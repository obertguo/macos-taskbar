# v0.1.0 Implementation Summary & v0.1.1 Roadmap

This document summarizes the completed implementation of **v0.1.0** of the native macOS Windows-style Taskbar (`Taskbar.app`), details the variances and refinements made relative to the initial architectural plans, and outlines the proposed roadmap and follow-up tasks for **v0.1.1**.

---

## 1. Executive Summary (v0.1.0)

Version **0.1.0** delivers a native, lightweight, and responsive Windows-style taskbar replacement for the macOS Dock built in pure Swift and AppKit. It operates without fragile private SkyLight APIs, relies entirely on public Accessibility and `NSWorkspace` APIs, and requires zero screen recording permissions for core functionality.

All planned milestones (**Milestone 0** through **Milestone 6**), along with subsequent user-requested refinements (constants centralization, typography and geometry configurability, overflow improvements, and Dock autohide delay management), have been fully implemented, tested, and verified.

### Key Metrics
- **Core Architecture:** Cleanly decoupled into `TaskbarCore` (pure Swift logic, zero AppKit/AX dependencies) and `TaskbarApp` (AppKit UI & system integration).
- **Unit Test Coverage:** 41 passing unit tests across 8 test suites with 100% success rate (`swift test`).
- **Resource Footprint:** Typical idle memory footprint < 35 MB RSS; ~0.0% idle CPU usage via event-driven architecture (no polling timers).
- **Display Support:** Multi-monitor support with independent window partitioning and dynamic screen reconfiguration handling.

## 2. Implemented Features & Architecture

### 2.1 Core Logic & Domain (`TaskbarCore`)
- **Window Management Domain:**
  - [`WindowInfo`](file:///Sources/TaskbarCore/Model/WindowInfo.swift), [`AppInfo`](file:///Sources/TaskbarCore/Model/AppInfo.swift), and [`WindowKey`](file:///Sources/TaskbarCore/Model/WindowKey.swift) models providing stable window identity across Space switches and title mutations.
- **Window Filtering & Partitioning:**
  - [`WindowFilter`](file:///Sources/TaskbarCore/Logic/WindowFilter.swift): Excludes system services (`com.apple.dock`, `ControlCenter`, `Spotlight`), utility panels, floating popovers, menus, and zero-sized non-minimized windows while properly retaining minimized windows.
  - [`ScreenAssignment`](file:///Sources/TaskbarCore/Logic/ScreenAssignment.swift): Accurately assigns windows to displays based on geometric intersection, with graceful fallback to the primary screen.
  - [`WindowStore`](file:///Sources/TaskbarCore/Logic/WindowStore.swift): Canonical state store maintaining per-display window lists, minimized states, and active space transitions.
- **Interaction & Layout State Machines:**
  - [`ClickPolicy`](file:///Sources/TaskbarCore/Logic/ClickPolicy.swift): Resolves left-click behaviors (unfocused $\to$ focus/raise; focused $\to$ minimize; minimized $\to$ restore/focus).
  - [`ButtonLayout`](file:///Sources/TaskbarCore/Logic/ButtonLayout.swift): Pure calculation of task button widths, title truncation, visibility thresholds, and overflow counts.
  - [`WorkAreaMath`](file:///Sources/TaskbarCore/Logic/WorkAreaMath.swift): Coordinate math determining whether maximized windows overlap the taskbar and computing non-collapsing clamped frames.
- **Configuration & Design Tokens:**
  - [`TaskbarConstants`](file:///Sources/TaskbarCore/Config/TaskbarConstants.swift): Centralized single source of truth for all layout dimensions, geometry ratios, debounce intervals, and system binary paths with detailed documentation.
  - [`TaskbarStrings`](file:///Sources/TaskbarCore/Config/TaskbarStrings.swift): Centralized user-facing string catalog for menu items, buttons, headers, and preset titles.
  - [`Settings`](file:///Sources/TaskbarCore/Config/Settings.swift): Codable user preferences persisted in `UserDefaults` (`com.local.taskbar`) with resilient decoding fallbacks for backward compatibility.

### 2.2 System Integration & Background Threading (`TaskbarApp`)
- **Dedicated Accessibility Thread:**
  - [`AXThread`](file:///Sources/TaskbarApp/Tracking/AXThread.swift): Runs a dedicated background `CFRunLoop` with strict messaging timeouts (0.3s) ensuring the AppKit main UI thread never hangs when third-party applications stall.
- **Event-Driven Window Tracking:**
  - [`AppTracker`](file:///Sources/TaskbarApp/Tracking/AppTracker.swift) & [`AXAppObserver`](file:///Sources/TaskbarApp/Tracking/AXAppObserver.swift): Observes `NSWorkspace` notifications (launches, terminations, space changes, activations) and per-app AX events (`kAXWindowCreatedNotification`, `kAXTitleChangedNotification`, `kAXWindowMiniaturizedNotification`, `kAXUIElementDestroyedNotification`).
- **Work Area Reservation (`WorkAreaEnforcer`):**
  - Monitors window movements and resizes on the AX background thread. When windows are vertically maximized or tiled to the bottom edge, it smoothly clamps their bottom frame above the taskbar. Includes recursion guards and debounce settling to prevent animation jitter.
- **System Dock Safety & Controller:**
  - [`DockController`](file:///Sources/TaskbarApp/System/DockController.swift): Manages native Dock hiding and restoration. Persists the user's original Dock configuration on first run. Automatically restores native Dock settings on quit or POSIX signals (`SIGINT`, `SIGTERM`, `atexit`).
  - Emergency standalone restore script: [`scripts/restore-dock.sh`](file:///scripts/restore-dock.sh).
- **Application Launching:**
  - [`Launcher`](file:///Sources/TaskbarApp/System/Launcher.swift): Triggers the configured start launcher (Spotlight via synthetic `CGEvent` Command+Space keystroke, Raycast via URL scheme/bundle, or custom path).

### 2.3 User Interface & Themes (`TaskbarApp/UI`)
- **Multi-Screen Panel Presentation:**
  - [`ScreenManager`](file:///Sources/TaskbarApp/UI/ScreenManager.swift) & [`TaskbarPanel`](file:///Sources/TaskbarApp/UI/TaskbarPanel.swift): Creates a non-activating `NSPanel` docked to the bottom edge of every connected monitor. Panels dynamically adapt to screen resolution or arrangement changes.
  - Native Full-Screen Space Handling: Panels cleanly suppress rendering when a native full-screen application space is active, restoring visibility upon switching back to standard desktop spaces.
- **Theme Engine:**
  - **Modern Hybrid:** Frosted translucency (`NSVisualEffectView`), subtle pill buttons, active state accents, and modern typography.
  - **Retro Classic:** Windows 95/98 aesthetic with classic gray (`#C0C0C0`), 3D raised/sunken beveled borders ([`BevelDrawing`](file:///Sources/TaskbarApp/UI/BevelDrawing.swift)), and retro typography.
- **Task Buttons & Overflow Handling:**
  - 1-to-1 window buttons displaying cached 16x16 app icons and window titles.
  - Pixel-perfect vertical centering balancing text baseline and icon frame.
  - Context menu on right-click (Minimize / Restore, Close Window, Quit App).
  - Overflow Chevron (`»`): Appears automatically when open windows exceed available bar space, opening a popup menu listing all overflowed windows for instant activation.
- **Status Menu & Live Preferences:**
  - [`StatusMenu`](file:///Sources/TaskbarApp/StatusMenu.swift): Menu bar icon providing live switching for Theme, Taskbar Height, Button Width / Overflow Threshold, Font Size, Icon Size, Dock Autohide Delay, WorkArea Nudger, Dock Restoration, and Quit.

### 2.4 Release Packaging & Versioning Subsystem (`scripts/`)
- **Automated Packaging (`scripts/package-release.sh`):**
  - Fail-fast execution (`set -euo pipefail`) aborting immediately on any unexpected error.
  - Pre-flight automated test verification (`swift test`) before compilation.
  - Automated semver bumping (`--patch`, `--minor`, `--major`) updating `config/build.env` and synchronizing `BuildConfiguration.swift` and `Info.plist`.
  - Atomic rollback error trap (`cleanup_on_failure` on `ERR INT TERM`): if tests, compilation, or packaging fail, `config/build.env` is automatically restored to its original state.
  - Assembles standalone DMG disk image (`hdiutil`) and ZIP archive (`ditto`) in `dist/` and computes SHA256 checksums (`SHA256SUMS.txt`).

### 2.5 Governance, Conventions & Changelog
- **Centralized Conventions Guide:**
  - [`docs/v0.1.0/CONVENTIONS.md`](file:///docs/v0.1.0/CONVENTIONS.md): Authoritative engineering reference detailing strict separation between `TaskbarCore` and `TaskbarApp`, `@MainActor` vs. `AXThread` concurrency rules, targeted drawing invalidation, icon caching, and system mutation safety invariants.
- **Formal Release Changelog:**
  - [`CHANGELOG.md`](file:///CHANGELOG.md): Initialized in root directory following [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) standards for tracking release history.

## 3. Differences: Initial Spec vs. Final Implementation

| Area / Feature | Initial Specification (Plans) | Implemented in v0.1.0 | Rationale & User Impact |
|---|---|---|---|
| **Dock Autohide Delay** | Hardcoded to extreme delay (`1000s`) to act as a permanent hide. | **User-configurable delay presets** in `Settings` and `StatusMenu` (`1000s`, `1.5s`, `1.0s`, `0.5s`, `0.0s`). | Allows users to choose between a strictly hidden dock or an intentional hover reveal, resolving hover-access expectations without sacrificing screen space. |
| **Geometry & Font Configurability** | Fixed bar height (30pt), fixed font (11pt), and fixed icon size (16pt). | **Fully user-configurable** via presets: Bar Height (26–44pt), Font Size (10–14pt), and Icon Size (14–24pt). | Supports different display scaling preferences and visual comfort while keeping layout proportions balanced. |
| **Button Width & Overflow Threshold** | Fixed button min width (28pt) allowing buttons to shrink to icon-only before overflow. | **Configurable min button width** (default **80pt**, presets 28–120pt) with dynamic title visibility threshold at 50pt. | Prevents window titles from prematurely vanishing into icon-only buttons on moderate window counts, triggering the overflow chevron earlier while keeping titles readable. |
| **Magic Numbers & String Literals** | Hardcoded dimension literals and strings scattered in layout, drawing, and menu classes. | Centralized into [`TaskbarConstants.swift`](file:///Sources/TaskbarCore/Config/TaskbarConstants.swift) and [`TaskbarStrings.swift`](file:///Sources/TaskbarCore/Config/TaskbarStrings.swift) with doc comments. | Establishes a single source of truth, eliminates code smells, and enables future localization/i18n. |
| **Spotlight Launching** | Proposed `NSWorkspace.shared.open(...)` with scheme or bundle. | Synthesized `CGEvent` Command+Space keystroke with Accessibility permission validation. | macOS Spotlight does not expose a public URL scheme or independent application bundle; synthetic keystrokes provide reliable invocation. |
| **Full-Screen Space Detection** | High-level suggestion to hide bars on full-screen spaces. | Concrete full-screen tracking in `WindowStore` (`isFullScreen`) and dynamic panel visibility suppression on full-screen spaces. | Prevents the taskbar from overlaying native full-screen applications (games, presentation tools, videos). |
| **Minimized Window Tracking** | Assumed standard `AXUIElement` window attribute retrieval. | Explicit edge-case handling for Chrome, Discord, Electron, VS Code, and Finder minimized states. | Electron and Chromium apps often report 0x0 frames or omit standard window attributes when minimized; special checks prevent them from disappearing from the bar. |
| **Vertical Text Centering** | Standard AppKit text drawing with fixed baseline offset. | Dynamically computed vertical centering offset balancing line height, button height, and icon center. | Custom font sizes and bar heights previously created visual vertical misalignment between text and icons. |
| **Packaging & Release Pipeline** | Basic manual build script (`build-app.sh --install`) only. | **Automated release packaging script** ([`scripts/package-release.sh`](file:///scripts/package-release.sh)) with fail-fast execution, automated semver bumping, atomic error rollback, DMG/ZIP generation, and SHA256 checksums. | Streamlines local release distribution for GitLab without needing expensive or insecure CI runners. |
| **Codebase Governance & Standards** | High-level principles in `README.md`. | Dedicated [`CONVENTIONS.md`](file:///docs/v0.1.0/CONVENTIONS.md) detailing architecture invariants, concurrency rules, and system safety protocols, paired with formal [`CHANGELOG.md`](file:///CHANGELOG.md). | Provides authoritative standards for human developers and AI coding agents. |

## 5. Roadmap & Next Steps for v0.1.1

The following features and enhancements are recommended for the **v0.1.1** release cycle:

### 5.1 Window Grouping & Stacking (Optional Mode)
- **Goal:** Group multiple windows belonging to the same application into a single taskbar button when window count exceeds a threshold (or as a persistent preference).
- **UX:** Clicking a grouped button displays a popup list/stack of that application's open windows (classic Windows 7 style).
- **Architecture:** Add `groupingMode` (`.never`, `.always`, `.autoOnOverflow`) to `Settings`, extend `ButtonLayout` to aggregate windows by `bundleIdentifier`, and create a `TaskButtonGroupView`.

### 5.2 Hover Window Previews (ScreenCaptureKit)
- **Goal:** Display a small live thumbnail preview of a window when hovering over its task button.
- **UX:** Hover popover showing window thumbnail, title, and quick action buttons (Close, Minimize).
- **Architecture:** Use `ScreenCaptureKit` (`SCScreenshotManager.captureImage`) with thumbnail caching. Note: Requires Screen Recording permission; should be an opt-in toggle in Settings.

### 5.3 Quick Launch / Pinned Applications
- **Goal:** Allow users to pin frequently used applications to the left side of the taskbar next to the Start button.
- **UX:** Pinned icons stay visible even when the app is not running. Clicking launches the app or switches to its active window.
- **Architecture:** Add `pinnedApps: [String]` (bundle IDs or paths) to `Settings` and render compact icon-only launch buttons in `TaskbarView`.

### 5.4 System Tray & Status Indicators (Right Edge)
- **Goal:** Add an optional clock, calendar flyout, or basic status indicators on the right edge of the taskbar.
- **UX:** Digital clock (e.g. `12:45 PM`), clicking opens a mini calendar flyout.
- **Architecture:** Add `showClock` toggle to `Settings`, create `TrayView` container positioned at the trailing edge of `TaskbarView`.

### 5.5 Edge Placement & Taskbar Auto-Hide
- **Goal:** Support placing the taskbar on other screen edges (Top, Left, Right) and an optional auto-hide mode for the taskbar itself.
- **UX:** Screen edge selector in Settings; taskbar slides offscreen when cursor leaves the edge and reveals on hover.
- **Architecture:** Update `TaskbarPanel` frame positioning and `WorkAreaEnforcer` clamping math for vertical or top screen edges.

### 5.6 Automated Stress Testing & CI Scripts
- **Goal:** Provide automated bash/python harness scripts in `scripts/` to spawn and tear down synthetic test windows across displays, measuring memory and latency during overflow conditions.
- **Architecture:** Add `scripts/benchmark-windows.sh` using AppleScript / macOS Terminal.
